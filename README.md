# QuickDirTree

Windows10以前のタスクバー内ツールバーから指定フォルダ内容を参照できる機能を、常駐アプリで再現。  
常駐アプリをクリックすることで登録したフォルダ内の内容がドロップダウンメニューで表示されます。

## インストール

Zipファイルを解凍、任意のフォルダに配置して起動してください。  
自動起動はしませんのでスタートアップへの登録は手作業で行ってください。

## 使い方

タスクバーに常駐アプリとして追加されます。  
常駐アプリを移動させタスクバー上に常に表示させてください。  
アプリをクリックすると登録フォルダの内容がドロップダウンメニューで表示されます。  
登録フォルダが無い場合はフォルダ選択ダイアログが起動します。  

登録フォルダはアプリアイコンの右クリックから追加・削除ができます。

## 設定ファイル

フォルダ設定は実行ファイルと同じフォルダの `appsettings.json`、言語設定は `lang.json` を読み書きします。
スタートアップのショートカットの「作業フォルダー」に依存しません。アプリは書き込み可能なフォルダに配置してください。
フォルダの登録・削除時に即時保存します。保存できない場合は警告を表示し、変更前の登録内容を維持します。終了操作は不要です。
設定は一時ファイルへの書き込み完了後に置き換えます。既存の設定が壊れている場合は、上書きせずに警告を表示して起動を中止します。
言語設定は初回のみ雛形を作成し、既存ファイルを終了時に上書きしません。

更新時は既存の `appsettings.json` と `lang.json` を実行ファイルと同じフォルダに残してください。
旧版で別の作業フォルダに保存された設定を引き継ぐ場合は、アプリを終了してから、その設定ファイルを実行ファイルと同じフォルダにコピーしてください。

## 検証

`dotnet run --project tests/Settings.Tests.csproj -c Release` で設定保存の回帰テストを実行します。
Windowsでは保存先ファイルがロックされている場合の保護も検証します。CIではテストとアプリのビルドを実行します。
